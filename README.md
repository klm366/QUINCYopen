# QUINCY standalone

The QUINCY terrestrial ecosystem model is:
* published via https://doi.org/10.17871/quincy-model-2019
* developed at https://gitlab.dkrz.de/quincy-community/quincy-model-developers/qs-development

QUINCY (QUantifying Interactions between terrestrial Nutrient CYcles and the climate system) has been developed at the MPI for Biogeochemistry as an alternative, more comprehensive representation of biogeochemical processes for ICON-Land. It is currently developed to run
* for individual sites driven by surface meteorology and
* coupled to a land-surface scheme of the global climate model ICON (https://code.mpimet.mpg.de/projects/iconpublic).

This QUINCY model version is running standlone driven by external forcing at site-level.

Documentation of information is available at
* https://docs.icon-model.org/land/land.html
* https://jsbach.gitlab-pages.dkrz.de/jsbach
